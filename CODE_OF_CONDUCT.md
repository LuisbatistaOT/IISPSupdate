# Code of Conduct

## Our Commitment

We are committed to a welcoming, respectful, and professional collaboration environment for all contributors.

## Expected Behavior

- Be respectful and constructive.
- Assume positive intent.
- Focus feedback on code and outcomes, not people.
- Share knowledge openly and help unblock others.

## Unacceptable Behavior

- Harassment, insults, or discrimination.
- Personal attacks or hostile language.
- Sharing private or sensitive data without permission.

## Enforcement

Project maintainers may remove comments, reject contributions, or block participation for behavior that violates this code.

## Scope

This code applies to all repository interactions, issue discussions, pull requests, and collaboration channels related to this project.
